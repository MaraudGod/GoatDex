# ⚙️ Automation

Scripts, shortcuts, extensions, and automation tools that make collecting, downloading, organizing, renaming, converting, and archiving media faster.

## Apple

### Apple Shortcuts
- iPhone, iPad, and Mac shortcuts for share-sheet downloads, file routing, renaming, conversion, metadata, and repetitive workflows.

### AppleScript
- macOS automation for Finder, browsers, media apps, file management, and batch workflows.

### Safari Extensions
- Safari extensions and userscripts useful for downloading, filtering, navigation, media handling, and site utilities.

## Browser Automation
- Userscripts
- Bookmarklets
- Browser extensions
- Batch link tools
- Link extractors

## Command-Line & Scripts
- Shell scripts
- Python utilities
- ffmpeg workflows
- yt-dlp workflows
- Batch processors

> Add only tools and workflows that materially improve collection, organization, conversion, or archiving.
