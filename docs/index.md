## What is GoatDex?

GoatDex is a **curated index**, not a media host. It is built to answer one question fast: **what is the best site or tool for what I am trying to do?**

### Legend

- 🐐 **GOAT** — personal top pick / best overall
- ⭐ **Recommended** — especially useful or reliable
- 🆓 **Free** — usable without payment
- 💰 **Paid** — paid account or premium features
- 📱 **Mobile** — works particularly well on mobile
- 🖥️ **Desktop** — desktop-focused tool
- 🌐 **Web** — browser-based
- ⚠️ **Caution** — read the note before using

> [!TIP]
> Use the search button at the top of the site to search the entire GoatDex index.
